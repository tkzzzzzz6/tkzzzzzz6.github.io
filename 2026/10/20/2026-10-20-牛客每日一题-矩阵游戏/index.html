#include <bits/stdc++.h>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n;
    cin >> n;

    long long answer = n;

    for (long long factor = 2; factor * factor <= n; ) {
        if (n % factor == 0) {
            n /= factor;
            answer += n;
        } else {
            ++factor;
        }
    }

    if (n > 1) {
        answer += 1;
    }

    cout << answer << '\n';

    return 0;
}
import sys

def solve():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    out = []
    idx = 1
    for _ in range(t):
        n = int(data[idx]); idx += 1
        ans = n
        factor = 2
        while factor * factor <= n:
            if n % factor == 0:
                n //= factor
                ans += n
            else:
                factor += 1
        if n > 1:
            ans += 1
        out.append(str(ans))
    sys.stdout.write('\n'.join(out))

if __name__ == '__main__':

易错点

  1. 不能只进行一次质因数试除：例如 需要连续除以 三次。
  2. 因子命中后不能立即递增：当前质因数可能重复出现，应该继续使用同一个因子。
  3. **剩余的大于 的数需要额外加 **：循环结束时剩余数一定是质数，最后还要从它变成 。
  4. **答案使用 long long**：虽然 ，但整个得分由多个状态累加，使用 64 位整数更稳妥。
  5. factor * factor <= n 是动态条件：每次除法后 变小，循环上界也会随之缩小。

可改进点

  • 当 更大（例如 或 ）时， 试除可能过慢，可以先做一步 Pollard-Rho 质因数分解，再按相同贪心策略处理。
  • 输入若只有单组数据，五种语言的 t 处理都可以简化。
  • 如果 是质数，答案就是 ，可以特判减少一次循环。

总结

本题看起来是在因数之间进行选择，实际上可以通过两个结论直接确定最优策略：

  1. 复合因数拆成多个质因数逐步处理，可以增加中间状态，因此更优；
  2. 相邻质因数中，较小的质因数应该先被除掉，这样中间状态更大。

所以只需要不断除以当前数的最小质因子，并把每次得到的新数累加到答案中即可。
